## Usage Instructions

### How to Update This Database

1. **Screenshot Method**
   - Search material on Tokopedia
   - Screenshot first 5 results
   - Extract prices manually
   - Update Option 1, 2, 3 columns

2. **Copy-Paste Method**
   - Select product listings
   - Copy prices
   - Paste into spreadsheet

3. **Average Calculation**
   ```
   Average = (Option 1 + Option 2 + Option 3) / 3
   ```

### Price Validity

- Prices subject to change
- Check Tokopedia regularly
- Consider shipping costs
- Factor in bulk discounts

### Regional Variations

- Jakarta: +10-15%
- Bali: +15-20%
- Surabaya: +5-10%
- Banyuwangi: Base price
